# FADEWELL HQ Gmail intake — Apps Script

This private script runs in `falka.falka35@gmail.com`, reads only messages from
`no-reply@vinted.pl`, and sends them to the authenticated `hq-gmail-ingest`
Supabase Edge Function. The existing HQ parser, evidence log, deduplication,
review queue, and ledger safety rules remain server-side.

## Installation

1. Create a standalone Apps Script project owned by `falka.falka35@gmail.com`.
2. Copy `Code.gs` and `appsscript.json` into the project.
3. Run `install` once and approve the Gmail, external request, and trigger
   permissions. The installation performs an immediate two-day replay and then
   schedules `syncVintedMail` every five minutes.
4. Verify a successful run in Apps Script Executions and a fresh
   `last_success_at` in HQ System before disabling the legacy OAuth poller.

The cursor advances only after every accepted batch. A one-hour overlap plus
server-side Gmail message ID deduplication makes retries safe.

Every request carries a short-lived Google access token generated by Apps
Script. The Edge Function validates it with Google UserInfo and accepts only
the verified `falka.falka35@gmail.com` identity. There is no long-lived shared
secret and no custom Google Cloud OAuth client.
