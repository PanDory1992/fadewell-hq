What the Gmail connection does

With the mailbox owner’s consent, FADEWELL HQ uses the Gmail API to identify transaction messages sent by Vinted. It extracts the minimum operational details needed to record purchase and sale evidence, prepare guarded ledger actions, and keep uncertain cases visible for human review.

The integration requests the gmail.modify permission because it can move one narrowly identified class of Vinted message (“Confirmation needed”) to Trash after recording the result. It does not send email.

Control stays with the mailbox owner

Access is limited to the designated FADEWELL mailbox and can be revoked at any time through the Google Account permissions page. Messages that are not from Vinted are not turned into HQ evidence.
