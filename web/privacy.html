Google OAuth

Scope and operator

This policy covers the Gmail integration used by FADEWELL HQ, a private operations tool for the FADEWELL vintage-denim business. The integration is operated by the owner of FADEWELL. Contact: mikita.matej35@gmail.com.

Google data accessed

After explicit consent, the integration uses the Gmail API scope https://www.googleapis.com/auth/gmail.modify. It accesses Gmail history and message metadata to detect new mail, then processes messages identified as coming from Vinted. For relevant Vinted messages it may access the sender, subject, timestamps, message and thread identifiers, message body, and transaction details such as item title, amount and transaction identifier.

The Gmail history feed may cause the service to retrieve metadata for new messages to determine their sender. Non-Vinted message content is not parsed into business data or stored as HQ evidence.

How data is used

Vinted message data is used only to record purchase and sale evidence, prepare or apply narrowly guarded ledger actions, reconcile transactions, identify cases requiring human review, and audit the result. The integration may move a Vinted “Confirmation needed” message to Trash after recording that action. It does not send messages, build advertising profiles, or use Google data for advertising.

Storage, sharing and security

The OAuth refresh token is stored in server-side protected storage. Relevant evidence may include message identifiers, sender, subject, timestamps, redacted normalized text, a content hash, extracted transaction fields and audit results. Data is transmitted over encrypted connections and access to the operational system is restricted to its owner.

Google user data is not sold. It is not shared with advertisers or data brokers. Supabase is used as the infrastructure provider for protected storage and processing. Data is retained only while needed for the operational record, audit, security and applicable record-keeping obligations.

Your choices

The mailbox owner can revoke access at any time from Google Account permissions. To request deletion of stored Gmail-derived data or ask a privacy question, contact mikita.matej35@gmail.com. Revoking access stops future Gmail synchronization but does not automatically remove records that must be retained for legitimate audit or legal purposes.

Google API Limited Use

Use of information received from Google Workspace APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
